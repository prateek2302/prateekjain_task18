# Task 18: JavaScript DOM and Event Handling

## Overview
An interactive web application showcasing DOM manipulation and event listeners in vanilla JavaScript.

## Features
- Dynamic header greeting initialized to "Hello" and updated to "Hello, [name]" upon clicking the Greet button or pressing Enter.
- Four interactive boxes that dynamically fill with their designated colors (Red, Blue, Green, Yellow) when clicked.
- Contrast adjustment ensuring legible text on filled box backgrounds.
- Minimal, centered layout styled with modern CSS.

## Files Included
- `index.html`: Web page semantic structure.
- `style.css`: Clean layout, flexbox alignment, and responsive styles.
- `script.js`: DOM event listeners and dynamic rendering logic.
- `Readme.md`: Overview and documentation.
